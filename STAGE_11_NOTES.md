# LAZOU Formations — Stage 11

## Pilotage financier du directeur

- Ajout du chiffre encaissé aujourd’hui sur le tableau de bord.
- Ajout du chiffre encaissé sur le mois courant.
- Ajout du nombre d’étudiants ayant encore un solde positif.
- Le nombre d’étudiants en impayé ouvre directement le module Recouvrement.
- Les montants sont recalculés à partir des paiements Firestore ; aucun solde calculé n’est stocké.
- Version : 1.5.0+10.
